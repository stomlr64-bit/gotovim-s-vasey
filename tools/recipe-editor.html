Добавить рецепт

Эта форма создаёт ZIP с дополнением для сайта. Она ничего не публикует и не меняет исходные файлы. Фотография в шапке не затрагивается.

Сначала выбери data/recipes.json из своей последней копии сайта. Затем заполни рецепт и скачай дополнение. После распаковки перенеси папки data и assets в копию сайта с заменой файла рецептов. Прежнюю копию сохрани.

Файл рецептов пока не выбран.

После добавления проверь рецепт в локальной копии. Для появления на GitHub Pages обновлённые файлы нужно отдельно загрузить в репозиторий.
